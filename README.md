# 💻 Personal Portfolio Website

A modern, responsive, and lightweight personal portfolio website built from scratch using pure HTML5, CSS3, and JavaScript. Designed to showcase my projects, technical skills, and background as a developer.

---

## ✨ Features

- 📱 **Fully Responsive Layout**: Designed to adapt seamlessly across desktop, tablet, and mobile devices.
- 🎨 **Clean & Modern UI**: Structured with a focus on readability, intuitive navigation, and clean visual design.
- ⚡ **Fast & Lightweight**: Built without external heavy frameworks for maximum performance and fast load times.
- 🛠️ **Project Showcase**: Highlights key web development projects with live demo links and GitHub repositories.
- 📧 **Contact Section**: Easy ways for prospective employers or collaborators to get in touch.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic markup for accessible and SEO-friendly web structure.
- **CSS3**: Custom styling, layout design (Flexbox/Grid), and smooth animations.
- **JavaScript (ES6+)**: Interactive UI features, DOM manipulation, and smooth scrolling.
